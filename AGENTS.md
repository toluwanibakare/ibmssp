# IBMSSP React Rebuild Guidelines

This workspace is for rebuilding the `ibmssp.org.ng` WordPress website in React.

## Brand Guidelines & Color Palettes
- **Primary Deep Teal**: `#305858`
- **Secondary Blue Grey**: `#798382`
- **Accent Slate Grey**: `#525656`
- **Text Dark Graphite**: `#1E1F1E`
- **Neutral Dark Iron Grey**: `#39838A`
- **Pure Dark Near Green**: `#040404`
- **Background**: `#ffffff` (No Dark Mode)

## Project Stack & Structure
- **Core Framework**: React 18+ (Vite)
- **Styling**: Vanilla CSS (No Tailwind unless requested)
- **Icons**: FontAwesome or custom SVG icons matching the original design
- **Aesthetics**: Premium, polished animations, micro-interactions, custom animations, clean headers/footers, identical placement of elements as original WordPress site.

## Coding Rules
- Maintain code cleanliness and module organization.
- Keep components small and reusable.
- Use client-side routing with standard navigation.
- Implement an interactive splash screen before showing the home page.
